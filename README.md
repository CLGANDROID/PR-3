# Phone Master

Android-додаток на тему «Збірка смартфона», реалізований на Jetpack Compose. Додаток за допомогою однієї кнопки послідовно проводить користувача через етапи складання смартфона: на кожному етапі змінюється зображення, текст і назва кнопки, а після завершення складання процес можна почати заново.

## Етапи роботи додатку

| Етап | Опис | Кнопка | Зображення |
|---|---|---|---|
| 1 | Корпус смартфона | «Встановити екран» | `phone_body.png` |
| 2 | Екран смартфона | «Встановити акумулятор» | `phone_screen.png` |
| 3 | Батарея смартфона | «Встановити камеру» | `phone_battery.png` |
| 4 | Камера смартфона | «Зібрати смартфон» | `phone_camera.png` |
| 5 | Смартфон готовий | «Почати заново» | `phone_complete.png` |

## Реалізація

- **Головний екран.** `MainActivity` створює інтерфейс через `setContent`, основний контейнер — `Scaffold`, всередині якого викликається composable-функція `Dashboard`. Елементи розміщені у `Column`.
- **Керування станом.** Поточний етап зберігається у `remember { mutableIntStateOf(1) }`. Після натискання кнопки значення `stage` збільшується на одиницю, а після п'ятого етапу повертається до 1: `1 → 2 → 3 → 4 → 5 → 1`.
- **Вибір тексту та зображення.** Залежно від `stage` за допомогою виразу `when` вибираються потрібні текстовий і графічний ресурси. Зображення відображаються через `Image` і `painterResource`, тексти зберігаються у `res/values/strings.xml` і отримуються через `stringResource`.
- **Обробка натискання кнопки.** Параметр `onClick` компонента `Button` змінює значення `stage`, після чого Compose перемальовує інтерфейс і показує наступний етап.
- **Передперегляд.** Для перевірки інтерфейсу створено функцію `DashboardPreview` з анотаціями `@Preview` та `@Composable`.

## Технології

- Kotlin
- Jetpack Compose (Material 3)
- Android Studio

## Структура проєкту

```
app/src/main/java/com/example/phonemaster/MainActivity.kt
app/src/main/res/drawable/            # зображення етапів складання
app/src/main/res/values/strings.xml   # тексти етапів і кнопок
```

## Запуск

1. Відкрити проєкт у Android Studio.
2. Дочекатися синхронізації Gradle.
3. Запустити конфігурацію `app` на емуляторі або фізичному пристрої.
